# DIHWorld Better Buses Tutorial Page Draft

## Page Title

DIHWorld Better Buses

## Short Description

Logic channel-strip starter buses for current DIHWorld Audio routing, cleaner chains, and safer level decisions.

## Overview

DIHWorld Better Buses is a practical Logic workflow set for using current DIHWorld Audio plug-in names, shorter bus chains, and a corrected level rule. Start buses around -18 dB, raise level only when the processor and source call for it, and output-match to bypass before approving tone, width, motion, or loudness.

## Recommended Main Routing

Source tracks feed Vocal Track when needed, then Drum Bus, Bass Bus, Vocal Bus, or Instrument Bus. Optional sends can feed FX Bus, Width Bus, Color Bus, or Master Bus. Family buses feed Master Bus, and Master Bus feeds Stereo Out.

| DIHWorld_Width_Bus | DEPTH_IMPACT_HYBRID_X -> PARALLAX -> NSR -> SESHAT | Depth, width perspective, spatial movement, and observation. |
| DIHWorld_Master_Bus | SPHYNX -> Maat -> ANKH -> SESHAT | Translation, balance, containment, observation. |

## Support Notes

- Keep SESHAT last as observation only.
- If a bus feels better louder, use the hotter level intentionally and output-match before approval.
- If a bus does not clearly help at matched loudness, bypass it or use a simpler chain.
