# Storefront Release Gates

As of this storefront documentation sweep, the public docs should not describe NTRSTLLR, NSR, or Mariana as blocked from publication.

## Current Rule

A product, bundle, demo, or tutorial download can be connected publicly only when the exact installer or download package is:

- Developer ID signed
- Apple notarized
- Stapled
- Gatekeeper verified
- Matched to current DIHWorld canon names and family placement
- Approved for the storefront path being published

## Current Storefront Corrections

- Use NSR as the current spatial movement name.
- Treat Platinum as primary Mastering Core with secondary Color support.
- Treat the public core offer as the five-plugin DIH Core Bundle including Mariana.

## If A New Block Is Needed

If listening, validation, or user feedback blocks a product, create a new dated note here with:

- Product name
- Reason for the block
- Files or builds affected
- Exact release gate that failed
- Required fix before publication
