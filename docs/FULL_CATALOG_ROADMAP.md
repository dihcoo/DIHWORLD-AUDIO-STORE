# Full Catalog Roadmap

The current storefront package promotes the DIH Core Bundle first: SacredVerb, Cathedral, DEBO, DrumKrushGlue, and Mariana.

The full catalog remains a 42-plugin, 13-family DIHWorld Audio suite. Companion bundles should expand the store by workflow, not by dumping every individual product into the first launch screen.

## Expansion Order

1. Publish SacredVerb, Cathedral, DEBO, DrumKrushGlue, and Mariana as the DIH Core Bundle products.
2. Add demo downloads and manuals for those five products.
3. Publish Better Buses as a tutorial/download product after package review.
4. Add companion bundle landing pages: Vocal Capture, Bass Foundation, Master Bus, Color Amp Tape, Spatial Motion, Beat Builder, and Creative Lab.
5. Import the full 42-product catalog as drafts from `data/plugin-catalog-42-current-canon.csv`.
6. Fill product pages by family, using glossary/preset language from the welcome-package PDFs.
7. Connect final installer downloads only after package verification.

## Product Page Template

Each product should include:

- Hero artwork
- One-sentence use case
- Family and smart-position label
- Overview
- Feature bullets
- Preset highlights
- Audio demo
- Walkthrough video
- Manual
- Compatibility
- Buy button
- Demo download
- FAQ

## Verification Language

Use this trust language wherever downloads appear:

DIHWorld Audio installers are released only after Developer ID signing, Apple notarization, stapling, and Gatekeeper verification.
