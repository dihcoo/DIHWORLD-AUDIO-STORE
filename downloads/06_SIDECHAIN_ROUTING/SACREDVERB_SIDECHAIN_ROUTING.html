SacredVerb Sidechain Routing

SacredVerb belongs on a deliberate FX send/return. Use the host sidechain as detector/control information; it is not mixed into the reverb return.

HOST KEY
kick, vocal, or rhythm source
→
SACREDVERB
detector / duck behavior
→
WET RETURN
living space in the mix

Logic Pro setup

  1. Place SacredVerb on an auxiliary FX return and keep the dry source on its own lane.
  2. Choose the trigger track from Logic’s native Side Chain menu above the plugin editor.
  3. Engage SacredVerb’s keyed/detector behavior, then set the response so the return moves around the source instead of masking it.
  4. Check the return in mono and level-match the bypass before judging the size or decay.

Routing rule: the external key controls the detector only. It does not become part of the audible reverb program.

Core placement

In the DIH Core workflow, use SILVER for source polish, OTIS for dynamics control, MARIANA for low-end foundation, PARALLAX for depth and motion, and SACREDVERB here as the living-space return. The five processors have defined lanes; do not serial-stack them on the master by default.
