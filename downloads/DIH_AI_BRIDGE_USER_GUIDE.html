DIHWorld Audio companion service

DIH AI Bridge

The DIH AI Bridge is a native macOS companion that reads a captured DIHWorld Audio plugin state and live readouts, then returns Ma’at direction plus Imhotep build suggestions. When it can identify a safe correction, it returns an exact parameter-level before/after patch so the plug-in can apply the change and keep it undoable.

DIHWorld scope: this service is currently for DIHWorld Audio plugin sessions. DMI TRACK is not connected to the bridge yet.

What it reads

Plugin context

Family, plugin identity, preset name/index, and the controls exposed by the current editor.

Live readouts

Host-authoritative input/output peaks, level delta when available, and parameter positions that need a second look.

Signal-flow role

The bridge uses the plugin’s DIH family and lane context to keep source, bus, send, and master decisions separate.

What it returns

Ma’at — direction + balance

A concise corrective direction: protect the source, check low-center stability, verify stereo integrity, or choose the lightest corrective stage.

Imhotep — build suggestions

A practical next move grounded in the captured state, such as preparing one source, assigning the correct family bus, or containing a combined program.

Capture → apply → undo

Read Signal captures the current state. Build returns the grounded correction and its before/after values. Apply commits a supported patch in the plug-in; Undo restores the exact prior values. If no safe correction is found, the bridge stays review-only and does not guess.

Safety and privacy boundary

  • Native delivery; no JUCE wrapper is required for the bridge.
  • The current provider is offline-canon. The bridge does not make network model calls or require provider credentials.
  • The bridge never runs from the audio thread or from processBlock; audio remains under the host and plugin DSP.
  • A captured signal can produce a bounded, reviewable parameter patch; protected controls are never eligible for patching, and no change is made until the user presses Apply.
  • The host meters remain authoritative. A bridge comment cannot override a DAW meter or a deliberate user decision.

Session flow

  1. Open a DIHWorld Audio plugin in the DAW.
  2. Capture/read the current editor state and signal readouts.
  3. Review Ma’at’s balance note and Imhotep’s build suggestion.
  4. Make the change manually or apply a supported proposal, then use the plugin’s undo path if needed.

The bridge is an optional assistant layer for DIHWorld Audio. It does not replace the manuals, host meters, or the engineer’s ears.
