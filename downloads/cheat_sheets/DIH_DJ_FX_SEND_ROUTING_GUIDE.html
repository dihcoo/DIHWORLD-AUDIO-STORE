DJ FX Send Routing

Use DIHWorld Audio in the DJ system you already have. This current workflow keeps the dry deck path in the mixer and places a DIHWorld plugin on a dedicated effect return for transitions, vocal throws, width, depth, and movement.

Current boundary: DIH Live is not in production yet. This guide does not promise direct Serato, Rekordbox, Traktor, or controller integration. It documents the effect-send/return workflow available now. Preset categories are a verification-gated delivery blueprint until each plugin passes its individual return test.

Reference signal flow

Deck A / B→DJ mixer FX Send→DIHWorld plugin return→FX Return→Master

The mixer remains authoritative for the dry signal. Put the plugin on an effect return, set it 100% wet, keep the return at unity, and perform intensity from the mixer send.

Logic Pro wiring

  • Connect the mixer FX Send to interface inputs 1–2, and interface outputs 1–2 to the mixer FX Return.
  • Create a stereo audio track, choose inputs 1–2, enable input monitoring, and route its output to the return pair.
  • Start at a 128-sample buffer (64 if stable), load one DIH effect, and set it 100% wet.
  • Set the mixer return to unity, then raise the channel send. Never route the FX Return back into the FX Send.

Ableton Live uses the same topology: monitored live input on the send pair and output on the return pair. Aim for interface peaks around –12 to –6 dBFS. The deck BPM is not automatically known to the Mac, so use free-time settings, tap tempo, or a manually set host tempo.

Best first returns

SACREDVERB

Transition tails and vocal throws. Start 100% wet with a short-to-medium decay.

PARALLAX

Controlled width and depth for breaks. Check mono and keep the low end centered.

NSR / NTRSTLLR

Spatial movement returns. Keep motion moderate on a club system.

EchoLocate

Source-position and vocal movement. Automate the send, not the dry source.

TEHUTI

Spectral movement when the host exposes a separate key/sidechain input.

Preset categories

The DJ delivery uses plugin-specific categories plus one single-return bank. That keeps each plugin’s purpose clear while giving a DJ one predictable place to start.

DJ RETURN / SPACE

SACREDVERB and PARALLAX. One wet return per plugin for tails, transitions, width, and depth.

DJ RETURN / MOTION

NSR, NTRSTLLR, and EchoLocate. Movement and source-position returns with send automation.

DJ RETURN / KEYED SPECTRAL

TEHUTI. Use when the host exposes a separate key/sidechain input.

DJ PREP / INSERT OR STEM

OTIS, ANUBIS, MARIANA, MONOLITH, DrumKrushGlue, MAAT, SPHYNX, PLATINUM, and IMHOTEP.

Single-return bank: DJ VOCAL THROW, TRANSITION SPACE, WIDE BREAK, DEEP RETURN, CLUB SAFE FX, and DRY/WET CUT. Each entry loads one existing plugin on one return lane; it is a delivery category, not a new multi-effect processor.

DJ rules that keep the return safe

  • Return plugins are 100% wet; the dry deck stays in the mixer.
  • Start with one processor per return; two is the live maximum for a first pass.
  • Leave the return at unity and use the send as the performance control.
  • Match perceived level before deciding that an effect is louder or “better.”
  • Check mono/correlation and output headroom before a club set.
  • Use sidechain only when the host provides a separate detector/key input.

Verification gate

Category entries become factory presets only after an individual plugin test confirms wet-only output, no feedback loop, matched return level, acceptable latency, mono/correlation safety, and click-free preset recall. Until then, use the catalog as a host-template and delivery blueprint.

Starter workflows

DJ VOCAL THROW

SACREDVERB on a wet return. Raise the send for the last phrase, then pull it back before the downbeat.

TRANSITION SPACE

SACREDVERB or EchoLocate with send automation for an intentional handoff between sections.

WIDE BREAK

PARALLAX at moderate width/depth for an intro or breakdown; verify mono first.

CLUB SAFE FX

SACREDVERB or PARALLAX with a conservative ceiling and matched return level.

Better as inserts or prepared stems

OTIS, ANUBIS, MARIANA, MONOLITH, DrumKrushGlue, MAAT, SPHYNX, PLATINUM, and IMHOTEP are usually better as inserts, family-bus processors, or pre-rendered DJ stems. Prepare a dry reference alongside the processed version so the DJ can choose confidently.
